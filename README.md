我在杭州，平时写 Java 后端，也会把自己想用的小工具做出来。这里有浏览器书签新标签页、PS5 到 OBS 的接流工具，还有一个能和朋友开房间玩的德州扑克小游戏。

## 最近在做

### [JTab · 把书签放回新标签页](https://github.com/JxQg/JTab)

浏览器书签直接就是数据源。打开新标签页就能找书签、整理文件夹，不用另建账号，也不用再维护一份书签。支持 Chrome、Edge 和 Firefox。

### [PlayStreamer · PS5 画面接进 OBS](https://github.com/JxQg/PlayStreamer)

在 Windows 上接收 PS5 广播，再把固定地址交给 OBS。可以用 OBS 推到 Bilibili，也可以把 OBS 投影窗口分享进 OOPZ。项目提供 Windows 安装包和中文操作文档。

[![下载 Windows 版](https://img.shields.io/badge/下载-Windows%20版-2EA44F?style=flat-square&logo=windows&logoColor=white)](https://github.com/JxQg/PlayStreamer/releases/latest) [![查看源码](https://img.shields.io/badge/查看-GitHub%20源码-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/JxQg/PlayStreamer)

### [J-Poker · 朋友间的德州扑克](https://github.com/JxQg/J-Poker)

开一个房间，把 8 位房间码发给朋友，2 到 10 人就能开始玩。牌局由服务端裁定，掉线后可以回来接着打。筹码只用于娱乐，没有现实价值。
